# target-audience-analyst

Скилл для Claude.

Собирает документ «Целевая аудитория» для B2B-проектов: профили ЦА, размер рынка, барьеры, триггеры переключения и границы для таргетинга. Разделяет факты и гипотезы и подкрепляет тезисы данными из веб-поиска.

## Когда использовать

- Описать ЦА или ICP для продукта, кампании, лендинга
- Оценить размер сегмента
- Дать таргетологу и копирайтеру рабочие границы аудитории

Не подходит для разведки болей по инфополю (market-analyze) и сегментации существующей базы (crm-consultant).

## Установка

**Claude Code.** Склонируйте репозиторий в папку скиллов:

```bash
git clone https://github.com/DingzhiboMike/target-audience-analyst.git ~/.claude/skills/target-audience-analyst
```

**Claude.ai / десктоп-приложение.** Скачайте репозиторий как ZIP (Code → Download ZIP) и загрузите его в настройках Claude, в разделе со скиллами.

После установки скилл включается сам, когда запрос подходит под его описание. Можно вызвать и явно — по имени `target-audience-analyst`.
